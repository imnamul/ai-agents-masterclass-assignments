## 📌 프로젝트 설명

LearnLog는 **LangGraph 기반 학습 습관 트래커 에이전트**입니다.

학습 목표를 말하면 AI가 도메인을 분석하고, 수준에 맞는 주차별 커리큘럼과 공식 학습 자료 링크를 자동 생성합니다. 이후 매일 체크인할 때마다 오늘의 주제와 자료를 제시하고, 퀴즈로 복습시키고, 하루를 마무리하는 학습 일기를 Notion에 자동 포스팅합니다.

단순한 챗봇이 아니라 **여러 노드가 조건 분기로 연결된 실제 에이전트 워크플로우**로 구현했고, LangGraph의 `interrupt()`와 체크포인트를 활용해 대화가 끊어져도 상태가 유지됩니다.

## ✨ 핵심 기능 설명

### 1. 맞춤 커리큘럼 자동 생성
학습 목표(예: "LangGraph", "영어 회화")와 현재 수준(입문/초급/중급/고급)을 입력하면, GPT-4o-mini가 도메인을 분석하고 전체 주차별 커리큘럼을 생성합니다. 각 주차마다 공식 문서·GitHub 등 학습 자료 링크 2~3개가 함께 제공됩니다.

### 2. 동적 AI 튜터 페르소나
커리큘럼 생성 시 도메인·수준에 맞는 튜터 시스템 프롬프트를 자동으로 생성합니다. "React 중급 튜터"와 "영어 회화 입문 튜터"는 서로 다른 교육 방식으로 응답합니다.

### 3. 매일 체크인 + 스트릭
오늘의 주제와 자료 링크를 먼저 보여주고, 학습 내용을 자유롭게 입력하면 AI 튜터가 핵심 개념을 짚어주는 피드백을 제공합니다. 연속 달성 일수(스트릭)가 누적되며 진도율도 실시간으로 업데이트됩니다.

### 4. 스페이스드 리피티션 퀴즈
오늘 배운 내용 기반 퀴즈 3문제를 자동 생성합니다. 퀴즈 히스토리에서 "약점 토픽"이나 "3일 이상 지난 토픽"을 감지해 복습 문제를 자동으로 포함시킵니다.

### 5. Notion 학습 일기 자동 포스팅
세션이 끝나면 오늘의 기분·목표·성취·회고·내일 계획이 담긴 학습 일기를 자동으로 Notion 데이터베이스에 저장합니다.

## 💬 엔지니어 클럽을 진행하며 느낀 점과 멤버들을 위한 팁

### 느낀 점

6주간의 엔지니어 클럽을 진행하면서 1차 목표였던 강의를 끝까지 들을 수 있었어요. 매주 강의를 듣고 과제를 진행하는 사이클이 생각보다 빠듯했는데, 지금 돌아보면 주말에 다음 주 강의를 미리 듣고 과제를 여유 있게 진행했다면 훨씬 깊이 있게 이해할 수 있었을 것 같아 아쉬움이 남습니다.

특히 최종 과제를 너무 늦게 시작하는 바람에 서비스 기획을 제대로 하지 못했고, 결과적으로 방향성과 완성도 모두 아쉬운 부분이 있어요. 그래도 LangGraph로 실제로 동작하는 에이전트를 처음부터 배포까지 직접 만들어봤다는 것 자체가 큰 수확이었습니다.

### 다른 멤버들을 위한 팁

**1. 최종 과제는 일찍 시작하세요**
과제 주제를 결정하는 데 생각보다 시간이 걸려요. 무엇을 만들지 방향이 정해져야 강의가 제대로 흡수됩니다. 3주차 전후로 주제를 잡고 기획을 시작하는 걸 추천합니다.

**2. 노드 하나에 interrupt 하나**
하나의 노드에서 `interrupt()`를 두 번 쓰면 LangGraph 체크포인트가 불안정해집니다. 사용자 입력이 두 번 필요하다면 노드를 반드시 분리하세요.

**3. interrupt 앞에서는 LLM 금지**
`interrupt()` 호출 전에 LLM을 쓰면 resume 시 해당 LLM이 재호출됩니다. LLM 결과가 필요하면 이전 노드에서 state에 저장한 뒤 interrupt 노드에서 읽어야 해요.

**4. CLAUDE.md에 규칙을 적어두면 AI가 기억합니다**
AI와 함께 작업할 때 가장 효과적이었던 건 `CLAUDE.md`에 아키텍처 규칙, 알려진 이슈, 자주 쓰는 명령어를 정리해두는 거였어요. 대화가 길어져도 AI가 프로젝트 규칙을 계속 지켜줬습니다.

**5. 일단 배포부터**
"기능 완성되면 배포하자"는 생각이 배포를 계속 미루게 만들어요. 기능이 덜 돼도 배포 파이프라인을 먼저 세팅해두면, 이후 기능 추가가 훨씬 편하고 동기부여도 됩니다.

## 🔧 현재 부족한 점 (솔직하게)

### 1. DB가 재시작하면 초기화됩니다
Streamlit Cloud는 파일 시스템이 휘발성이라, 앱이 슬립 후 재시작되면 SQLite DB가 날아갑니다. 커리큘럼·스트릭·퀴즈 히스토리가 모두 초기화돼요. 지금은 "일단 배포 우선"으로 수용했지만, 실제 서비스라면 치명적인 문제입니다.

### 2. 단일 사용자 전용
현재 `thread_id`가 앱 전체에서 하나로 고정되어 있어서, 여러 사람이 같은 URL로 접속하면 상태가 섞입니다. 개인용 도구로는 충분하지만 공유 서비스로는 부적합합니다.

### 3. 학습 자료 URL의 품질 보장이 어렵습니다
LLM이 공식 문서 URL을 생성할 때 실제로 존재하는 주소를 잘 생성하지만, 가끔 존재하지 않는 URL을 만들어내기도 합니다. 현재는 프롬프트 제약("확실하지 않으면 포함하지 말 것")으로 어느 정도 방어하고 있지만, URL 유효성 검증 로직은 없습니다.

### 4. ACTION_SELECT가 텍스트로 노출됩니다
체크인 응답 후 액션 선택 노드(`checkin_action`)에서 버튼을 렌더링해야 하는데, 간혹 "ACTION_SELECT"라는 원시 텍스트가 대화 버블로 표시되는 타이밍 이슈가 있습니다. LangGraph의 interrupt 재개 시점과 Streamlit 렌더링 사이의 간극에서 발생합니다.

### 5. 커리큘럼이 영어로 나올 때가 있습니다
LangGraph처럼 영어 자료가 주를 이루는 주제는 일별 토픽이 영어로 생성되는 경우가 있어요. 프롬프트에서 언어를 강제하지 않았기 때문입니다.

## 🚀 차후 개선 방향

### 단기 (v1.2)
**영속적인 DB 연동** — Supabase PostgreSQL + `langgraph-checkpoint-postgres`로 교체하면 Streamlit Cloud 재시작과 무관하게 상태가 유지됩니다. 스트릭이 유지되어야 학습 습관 트래커로서 의미가 생깁니다.

**멀티유저 지원** — 로그인(Google OAuth 등)으로 `thread_id`를 사용자별로 분리하면 공유 서비스로 전환할 수 있습니다.

**커리큘럼 언어 통일** — 시스템 프롬프트에 "한국어로 작성할 것" 명시 + 생성 후 언어 감지 검증.

**학습 자료 URL 검증** — 생성된 URL에 HTTP HEAD 요청을 보내 404면 해당 항목을 제거하는 후처리 단계 추가.

### 중기 (v2.0)
**습관 트랙 + 학습 트랙 통합** — 운동·독서 같은 자유 습관 항목과 커리큘럼 학습을 하나의 세션에서 처리. 사이드바에서 항목별 스트릭을 개별로 확인 가능.

**아침/저녁 세션 분리** — 아침: 오늘의 주제·자료 브리핑 / 저녁: 학습 내용 체크인·퀴즈·일기. 하루를 구조적으로 지원하는 형태.

**Google Calendar 연동** — 커리큘럼 일정을 캘린더에 자동 등록해서 리마인더까지 연결.

### 장기
**커리큘럼 파일 import** — 사용자가 직접 만든 커리큘럼(CSV/Notion 테이블 등)을 업로드해서 LearnLog 에이전트에 연결.

**학습 분석 대시보드** — 누적된 quiz_history와 streak 데이터를 시각화해서 "내 취약 토픽", "가장 많이 틀린 유형" 등을 리포트로 제공.
